# Global News Platform

An AI-powered automated news platform built with Next.js, statically exported to Cloudflare Pages. Inspired by BBC, Reuters, Bloomberg, and The Guardian.

## Architecture

```
┌─────────────────────────────────────────────────┐
│              RSS Sources (BBC/NYT/Guardian)      │
└──────────────────┬──────────────────────────────┘
                   │ fetch every N hours
┌──────────────────▼──────────────────────────────┐
│         Automation Pipeline (scripts/)           │
│  ┌─────────┐ ┌──────────┐ ┌──────────────────┐  │
│  │ Ingest  │→│Process   │→│ MDX Writer       │  │
│  │ (fetch) │ │(topic,   │ │ (src/data/)      │  │
│  │         │ │ tag, fm) │ │                  │  │
│  └─────────┘ └──────────┘ └──────────────────┘  │
│  ┌─────────┐ ┌──────────┐ ┌──────────────────┐  │
│  │Sitemap  │ │RSS Feed  │ │ Git Commit/Push  │  │
│  │Gen      │ │Gen       │ │                  │  │
│  └─────────┘ └──────────┘ └──────────────────┘  │
└──────────────────┬──────────────────────────────┘
                   │ build (Next.js static export)
┌──────────────────▼──────────────────────────────┐
│           Cloudflare Pages (static hosting)      │
│  /out → globalnews.news                          │
└─────────────────────────────────────────────────┘
```

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | Next.js 15 (App Router, Static Export) |
| Language | TypeScript |
| Styling | Tailwind CSS 3 + CSS Variables |
| Typography | Tailwind Typography plugin |
| Animation | CSS transitions + IntersectionObserver |
| Icons | Lucide React |
| Fonts | Inter (sans), Merriweather (serif), Playfair Display (headline) — self-hosted via `next/font` |
| MDX | next-mdx-remote + rehype/remark plugins |
| UI | Radix UI primitives (Dialog, Slot) |
| CMS | File-based (MDX files in `src/data/articles/`) |
| Hosting | Cloudflare Pages (static export) |
| Automation | Node.js scripts + GitHub Actions |
| RSS Ingestion | rss-parser |

## Quick Start

### Prerequisites

- Node.js 20+ (use `.nvmrc`: `nvm use`)
- npm 10+
- Git

### Local Development

```bash
# 1. Clone and install
git clone <repo-url>
cd global-news-platform
npm install

# 2. Start dev server
npm run dev

# 3. Open http://localhost:3000
```

The dev server supports hot reload. Edit MDX files in `src/data/articles/` to see live changes.

### Build

```bash
npm run build
```

Outputs a fully static site to `out/`. All pages are pre-rendered (SSG). No server required.

## Automation

The platform includes a complete automation pipeline for hands-free news ingestion.

### Local Pipeline

```bash
# Full pipeline (ingest → build → commit)
npm run pipeline

# Dry run (no files written)
npm run pipeline:dry

# Ingest only (no build/commit)
npm run ingest

# Regenerate sitemap/RSS only
npm run sitemap
npm run feed

# Verify build (typecheck + build)
npm run verify
```

### Scheduled Automation (Windows)

```powershell
# Run as Administrator to install hourly task
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
```

### GitHub Actions (CI/CD)

The repository has two workflows:

| Workflow | Trigger | What it does |
|----------|---------|-------------|
| **Deploy** | Push to `main` + manual | Typecheck → Build → Deploy to Cloudflare Pages |
| **Ingest** | Every 3 hours + manual | Ingest RSS → Build → Commit → Deploy |

### Environment Variables

| Variable | Where | Purpose |
|----------|-------|---------|
| `CLOUDFLARE_API_TOKEN` | GitHub Secrets | Cloudflare API token (Pages Write permission) |
| `CLOUDFLARE_ACCOUNT_ID` | GitHub Secrets | Cloudflare account ID |
| `SITE_URL` | `.env.production` | Production site URL |
| `GIT_DISABLED` | `.env.local` | Skip git operations locally |

## Adding an Article Manually

Create a new `.mdx` file in `src/data/articles/`:

```mdx
---
title: "Your Article Title"
excerpt: "A compelling summary of the article."
category: "Technology"
author: "James Chen"
authorSlug: "james-chen"
publishedAt: "2026-05-15T10:00:00Z"
image: "/images/articles/your-image.jpg"
imageAlt: "Description of the image"
tags: ["technology", "innovation", "artificial-intelligence"]
featured: false
breaking: false
trending: false
---

Your article content here. Use **Markdown** formatting.

## Section Heading

Regular paragraphs with inline `code` and [links](https://example.com).

- List items
- More items
```

The article is automatically picked up on the next build. No database or API needed.

## Deployment

### Cloudflare Pages (Recommended)

1. Push repository to GitHub
2. In Cloudflare Dashboard → Pages → Create a project
3. Connect your GitHub repository
4. Set build command: `npm run build`
5. Set build output: `out`
6. Add environment variables:
   - `SITE_URL`: `https://globalnews.news`
7. Deploy

### Manual (from local machine)

```bash
# Build the site
npm run build

# Deploy using wrangler (requires CLOUDFLARE_API_TOKEN)
npx wrangler pages deploy out --project-name=global-news-platform --branch=main
```

### Custom Domain

1. In Cloudflare Pages → your project → Custom domains
2. Add `globalnews.news` (and `www.globalnews.news`)
3. Update `SITE_URL` in environment variables
4. Update `src/lib/constants.ts` → `siteConfig.url`

## RSS Sources

Configure RSS sources in `scripts/config/sources.json`:

```json
{
  "sources": [
    {
      "url": "https://feeds.bbci.co.uk/news/world/rss.xml",
      "category": "world",
      "label": "BBC World"
    }
  ]
}
```

Each source maps to a category (world, politics, technology, business, science, health, climate, culture, sports, opinion). The pipeline fetches, deduplicates, extracts topics, generates tags, and writes MDX files automatically.
